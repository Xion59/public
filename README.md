## Installation & Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/Xion59/public.git
   cd public
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```
